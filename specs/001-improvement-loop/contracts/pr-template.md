# Contract: PR テンプレート

配置: `.github/pull_request_template.md`。すべての PR の説明欄の初期値になる。

## セクション(この順序)

```markdown
## 関連 Issue
<!-- 例: Closes #12(反映する改善提案ごとに書く)/ Refs #3 -->

## 変更内容
<!-- 何を、なぜ変更したか -->

## 確認したこと
<!-- テスト・検証・quickstart の実施結果など -->

## 振り返り
<!-- 小さな変更で特になければ「特になし」と書く。改善提案は、マージ前に Issue を登録して番号を書く -->
- うまくいった点:
- 問題点:
- 改善提案: <!-- 特になし / #N -->

## マージ前チェック
- [ ] 振り返りの 3 項目を記入した
- [ ] 振り返りで出た改善提案を Issue として登録し、番号を書いた
- [ ] 憲章を改定した場合、PR タイトルに新しいバージョンを書いた
```

## ルール

- 振り返りの 3 項目は空欄にしない(FR-013, FR-015)。
- 「改善提案」には `特になし` または `#N` の形式で書く(FR-014)。
- 改善提案を反映する PR は、提案ごとに `Closes #N` を書く(FR-010, FR-011)。
